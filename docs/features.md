# MiMo Voice — Features List

## Phase 1: Core (Build First)

1. **Voice-to-Voice Translation**
   - User speaks → Whisper transcribes → MiMo translates → MiMo Speech speaks
   - Target: under 5 seconds end-to-end

2. **Conversation Mode** (from RTranslator)
   - Two people, two languages
   - Both hear translation in their language

3. **Walkie-Talkie Mode** (from RTranslator)
   - Push-to-talk for quick street phrases

4. **Language Auto-Detection**
   - Whisper detects language automatically

## Phase 2: Smart Translation

5. **Context Engine**
   - Auto-detect: restaurant, hospital, airport, hotel, street
   - GPS + conversation content determines context
   - "check" = bill at restaurant, verify at office

6. **Politeness Levels**
   - Casual / Formal / Emergency
   - Auto-adjusts or user sets manually

7. **Idiom Handler**
   - "Break a leg" → "Good luck" (not literal)

8. **Domain Modes**
   - Medical: correct medical terms, allergy phrases
   - Legal: contract language, formal declarations
   - Business: meeting vocabulary, professional tone
   - Travel: directions, food, accommodation
   - Emergency: "Call ambulance", "I'm allergic to..."

## Phase 3: Visual Translation

9. **Camera Translation**
   - Point at menu, sign, or document
   - MiMo Omni reads and translates

10. **Menu Translator**
    - Reads menus with dish descriptions
    - Flags allergens

11. **Sign Reader**
    - Translates street signs with navigation context

## Phase 4: Travel Intelligence

12. **Cultural Tips**
    - "In Japan, don't tip at restaurants"
    - Auto-triggered based on location

13. **Phrase Book**
    - Auto-generates useful phrases for current situation

14. **Emergency Mode**
    - One-tap emergency phrases in local language
    - Shows emergency numbers for current country

15. **Currency Converter**
    - "That costs 3,500 yen" → "About $23 USD"
